# 🏆 Countdown World Cup 2026 (Rainmeter Skin)

An elegant dynamic widget for Rainmeter designed to accurately count down to the opening whistle of the 2026 World Cup. 

Taken from the project "Countdown in Lua" (https://visualskins.com/skin/countdown-lua) - by 66VI (https://www.deviantart.com/66vi).

## ✨ Características
- **100% Dynamic Alignment:** The cup logo is automatically centered by calculating the actual width of the text in real time.
- **Official Typography:** It includes and locally integrates the official tournament source **We Are 26**.
- **Sports Format:** Clean digital structure with leading zeros (`00`) and aesthetic spacing.
- **Optimized Code:** Mathematical calculation logic delegated to a support script in Lua.

## 🚀 Setup
1. Go to the **Releases** section on the right of this repository.
2. Download the executable file `.rmskin`.
3. Double-click the downloaded file to install it using Rainmeter's native installer.

## 🛠️ Technologies
- **Rainmeter** (Skin Engine: https://www.rainmeter.net/)
- **Lua Scripting** (Clock logic)
